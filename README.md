**Jenny Mod Minecraft** is a companion NPC pack for Java 1.20.1 / 1.21.1 and jenny mod minecraft bedrock / PE. Animations, Forge loader, CurseForge pack name, MCPE / APK path. Skin pack optional.

## Getting Started
1. Download v2.1.0.
2. Extract `JennyMod.zip`.
3. Java: drop the jar into `mods` on Forge 1.20.1 or 1.21.1.
4. Bedrock: import the addon / APK path in `files/pe/`.
5. Optional skin pack from `files/clip/`.

## FAQ

**1.20 vs 1.21.1?**
Both jars ship. Pick the loader you run.

**Bedrock / APK?**
`files/pe/` is the PE / MCPE / Android path.

**Forge?**
1.20.1 Forge is the Java default. 1.21.1 uses the same entity id.

## Requirements
Java: Minecraft 1.20.1 or 1.21.1 + Forge. Bedrock: PE / MCPE build that loads addons.
